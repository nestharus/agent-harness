# WU-0A-10 Contract: BackendSpanEvent Runtime Event

## Ownership

This WU owns the shared BackendSpanEvent DTO, status taxonomy, span builder, builder error taxonomy, and the canonical `IpcEvent<BackendSpanEvent>` runtime-topic binding. It does not own event-bus emission, producer wiring, Tauri command registration, GraphStore persistence, provider execution, worker execution, recovery behavior, budget behavior, or audit logging.

## BackendSpanEvent

`BackendSpanEvent` serializes as a JSON object with these fields:

- `span_event_id`: required string generated by `emit_backend_span`.
- `trace_context`: required WU-0A-09 `TraceContext` object.
- `span_name`: required string supplied by the caller.
- `started_at`: required string supplied by the caller.
- `completed_at`: optional string supplied by the caller for completed spans.
- `status`: required `BackendSpanStatus`.
- `error_ref`: optional string supplied by the caller for failed spans.

Optional fields are omitted when absent. Unknown JSON fields are rejected by Rust serde and TypeScript validators.

## BackendSpanStatus

`BackendSpanStatus` serializes as one of these exact lowercase strings:

- `started`
- `completed`
- `failed`

Parsing is exact-match against these strings. No trimming, case folding, aliasing, or prefix matching is allowed.

## Builder

```text
emit_backend_span(
  trace_context: TraceContext,
  span_name: string,
  started_at: string,
  completed_at?: string,
  status: BackendSpanStatus,
  error_ref?: string
) -> Result<BackendSpanEvent, BackendSpanError>
```

Successful creation:

- Generates a non-empty opaque `span_event_id`.
- Preserves the supplied nested `trace_context`.
- Preserves the supplied `span_name`.
- Preserves the supplied `started_at`.
- For `started`, sets `status: "started"` and omits `completed_at` and `error_ref`.
- For `completed`, sets `status: "completed"` and preserves `completed_at` when `completed_at >= started_at`.
- For `failed`, sets `status: "failed"` and preserves `error_ref`.

## Errors

`BackendSpanError` serializes as one of these exact strings:

- `EmptySpanName`
- `CompletedBeforeStarted`
- `FailedWithoutErrorRef`
- `TraceContextInvalid`

Builder behavior:

- `span_name == ""` returns `EmptySpanName`.
- `status == "completed"` with `completed_at < started_at` returns `CompletedBeforeStarted`.
- `status == "failed"` without `error_ref` returns `FailedWithoutErrorRef`.
- A supplied `TraceContext` that fails WU-0A-09 contract validation returns `TraceContextInvalid`.

## Runtime Topic Binding

Backend span payloads are wrapped in `IpcEvent<BackendSpanEvent>` only with `topic: "runtime"` in Phase 0A. This WU provides the canonical envelope helper and fixture; it does not publish the event to a bus.

Graph, render, provider, optimizer, worker, question, recovery, budget, and audit topics carry no BackendSpanEvent payloads in Phase 0A.
