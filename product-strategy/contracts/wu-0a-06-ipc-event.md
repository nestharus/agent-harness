# WU-0A-06 Contract: IpcEvent Envelope Type

## Ownership

This WU owns the shared generic IPC event envelope, event construction helper, raw-topic validation helper, and event-construction error taxonomy. It does not own IPC subscriptions, event bus implementation, Tauri command registration, domain payload schemas, GraphStore, providers, agents, workers, budget accounting, audit persistence, or trace context creation.

## IpcEvent

`IpcEvent<T>` serializes as a JSON object with these fields:

- `event_id`: required non-empty string generated by `build_ipc_event`.
- `workspace_id`: required string supplied by the caller.
- `topic`: required `EventTopic` from WU-0A-05.
- `payload`: required generic payload supplied by the caller.
- `created_at`: required non-empty timestamp string generated by `build_ipc_event`.
- `trace_context_id`: optional string supplied by the caller.

Optional fields are omitted when absent. Unknown JSON fields are rejected by Rust serde and TypeScript validators. The envelope preserves payload shape but does not validate domain payload semantics.

## Builder

```text
build_ipc_event<T>(
  workspace_id: string,
  topic: EventTopic,
  payload: T,
  trace_context_id?: string
) -> Result<IpcEvent<T>, IpcEventError>
```

Successful creation:

- Generates a non-empty opaque `event_id`.
- Generates a non-empty `created_at` timestamp string.
- Preserves the supplied `workspace_id`.
- Preserves the supplied `topic`.
- Preserves the supplied generic `payload`.
- Omits `trace_context_id` when not supplied.
- Preserves `trace_context_id` when supplied.

The Rust builder requires `T: Serialize` and maps payload serialization failures to `PayloadSerializationFailed` before returning an event.

## Raw Topic Builder

```text
build_ipc_event_from_raw_topic<T>(
  workspace_id: string,
  raw_topic: string,
  payload: T,
  trace_context_id?: string
) -> Result<IpcEvent<T>, IpcEventError>
```

This fixture-facing helper parses `raw_topic` with the WU-0A-05 parser before building the event. Any undocumented raw topic string returns `UnknownTopic`.

## Errors

`IpcEventError` serializes as one of these exact strings:

- `EmptyEventId`
- `EmptyWorkspaceId`
- `UnknownTopic`
- `PayloadSerializationFailed`

Construction behavior:

- A generated empty event ID returns `EmptyEventId`.
- `workspace_id == ""` returns `EmptyWorkspaceId`.
- An undocumented raw topic string returns `UnknownTopic`.
- A payload that fails serde serialization returns `PayloadSerializationFailed`.

- `canonical-event.json`: full `IpcEvent<T>` object with `trace_context_id`.
- `minimal-event.json`: `IpcEvent<T>` object without `trace_context_id`.
- `build-success.json`: documented successful builder input and expected preserved fields.
- `build-errors.json`: documented builder error inputs, including `UnknownTopic` and `PayloadSerializationFailed`.
- `ipc-event-errors.json`: all documented error strings in canonical order.
- `invalid-events.json`: TypeScript validator rejection cases.
