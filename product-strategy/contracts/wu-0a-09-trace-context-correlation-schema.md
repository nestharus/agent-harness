# WU-0A-09 Contract: TraceContext Correlation Schema

## Ownership

This WU owns the shared TraceContext DTO, actor taxonomy, context creation helper, and creation error taxonomy. It does not own GraphStore persistence, audit-log persistence, provider execution, agent routing, worker lineage validation beyond the local parent/invocation rule, Tauri IPC commands, or durable correlation ID storage.

## TraceContext

`TraceContext` serializes as a JSON object with these fields:

- `correlation_id`: required string generated by `create_trace_context`.
- `workspace_id`: required string supplied by the caller.
- `invocation_id`: optional string supplied by the caller.
- `parent_invocation_id`: optional string supplied by the caller.
- `actor`: required `TraceActor`.
- `graph_ref`: optional string supplied by the caller.
- `audit_event_ref`: optional string supplied by the caller.

Optional fields are omitted when absent. Unknown JSON fields are rejected by Rust serde and TypeScript validators.

## TraceActor

`TraceActor` serializes as one of these exact lowercase strings:

- `user`
- `orchestrator`
- `worker`
- `optimizer`
- `reviewer`
- `backend`
- `system`

Parsing is exact-match against these strings. No trimming, case folding, aliasing, or prefix matching is allowed.

## Creation Helper

```text
create_trace_context(
  workspace_id: string,
  actor: string,
  invocation_id?: string,
  parent_invocation_id?: string,
  graph_ref?: string,
  audit_event_ref?: string
) -> Result<TraceContext, TraceContextError>
```

Successful creation:

- Generates a non-empty opaque `correlation_id`.
- Preserves the supplied `workspace_id`.
- Parses and preserves the supplied `actor`.
- Omits invocation, graph, and audit fields when not supplied.
- Preserves `invocation_id`, `parent_invocation_id`, `graph_ref`, and `audit_event_ref` when supplied.

## Errors

`TraceContextError` serializes as one of these exact strings:

- `EmptyWorkspaceId`
- `UnknownActor`
- `ParentWithoutInvocation`

Creation behavior:

- `workspace_id == ""` returns `EmptyWorkspaceId`.
- An undocumented actor string returns `UnknownActor`.
- A supplied `parent_invocation_id` without `invocation_id` returns `ParentWithoutInvocation`.
- Empty optional strings are preserved when supplied; this WU only validates the parent/invocation relationship.
