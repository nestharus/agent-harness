# WU-0A-09 Proposal: TraceContext Correlation Schema

## Design

Add a narrow TraceContext contract shared by Rust and TypeScript:

- Rust owns `TraceContext`, `TraceActor`, and `TraceContextError` in `src-tauri/src/contracts/trace_context.rs`.
- Rust behavior lives in `src-tauri/src/tracing/trace_context.rs`, including exact actor parsing and `create_trace_context(...)`.
- TypeScript mirrors the DTO, actor union, error union, and fixture parsers in `src/contracts/trace-context.ts`.
- Contract fixtures under `product-strategy/contracts/fixtures/wu-0a-09/` are the cross-language source of truth for actor names, canonical context shape, success inputs, and error inputs.

`create_trace_context` accepts the actor as a raw string so `UnknownActor` remains reachable at the creation boundary. The successful result stores actor as the typed `TraceActor` enum and serializes it as the documented lowercase string.

Correlation IDs are generated internally by the Rust helper as non-empty opaque strings. Phase 0A does not require a durable ID registry or graph-store persistence, so the helper only guarantees a fresh process-local generated value and no externally meaningful format.

## Scope

- Add the TraceContext Rust serde DTO and error taxonomy.
- Add exact actor parsing and context creation validation.
- Add the matching TypeScript DTO and runtime shape validators.
- Add shared contract fixtures and Rust/Vitest contract tests.

## Anti-Scope

- No GraphStore schema, graph writes, or graph reference validation.
- No audit-log implementation or audit event validation.
- No provider, agent, worker, optimizer, reviewer, or orchestration behavior.
- No Tauri command registration or IPC surface.
- No durable correlation ID persistence.

## Supported Surface

- Deployment mode: local Phase 0A Tauri scaffold and library contract tests.
- Customer cohort: internal contract consumers and future Phase 0A slices importing the Rust/TS DTOs.
- Public paths: Rust library consumers and TypeScript contract importers.
- Adjacent paths in blast radius: existing contract modules, `lib.rs` module declarations, and `bun run *` / Cargo checks.
- Migration path: additive contract, tracing module, fixtures, and tests.
- Rollback path: remove the added TraceContext modules, fixtures, contract doc, proposal, and module declarations.
- Observability: Rust contract tests and Vitest tests expose DTO drift, actor drift, create success behavior, and all documented error variants.

## Assumptions

- A1: Phase 0A only needs opaque non-empty correlation IDs. Evidence: WU contract only requires `correlation_id: string` and acceptance criteria say non-empty. Invalidated by a revised WU requiring UUID format, monotonic order, or persistence.
- A2: Graph and audit references are opaque optional strings in this WU. Evidence: WU contract names `graph_ref?: string` and `audit_event_ref?: string` but excludes GraphStore/provider/agents work. Invalidated by a revised WU requiring reference existence checks.
- A3: `UnknownActor` must be enforced at the creation boundary from raw actor input. Evidence: acceptance criteria explicitly call `create_trace_context(workspace_id, "unknown", ...)`. Invalidated by a revised signature that makes unknown actors impossible before the helper runs.

## Test Intent

- Rust DTO shape and serde round-trip: verify the canonical fixture field set, required fields, optional fields, and actor serialization. Risk: Rust/TS contract drift. Level: particular-integration. Fixture: `canonical-context.json`. Assumptions: A1, A2.
- Rust actor taxonomy: verify every documented actor serializes/deserializes exactly and unknown strings are rejected. Risk: actor taxonomy drift. Level: particular-integration. Fixture: `trace-actors.json`.
- Rust create success behavior: verify minimal and full invocation-lineage inputs preserve all supplied fields and generate non-empty correlation IDs. Risk: creation helper drops optional lineage or references. Level: unit. Fixtures: `create-success-minimal.json`, `create-success-full.json`. Assumptions: A1, A2, A3.
- Rust error reachability: verify `EmptyWorkspaceId`, `UnknownActor`, and `ParentWithoutInvocation` are all reachable through documented create inputs. Risk: unreachable or renamed error surface. Level: unit. Fixture: `create-errors.json`. Assumption: A3.
- TypeScript DTO and error parity: verify TypeScript accepts fixture-shaped TraceContext values, rejects unknown fields or bad actors, and keeps the error union aligned with fixtures. Risk: TypeScript accepts values Rust rejects. Level: unit/typecheck. Fixtures: `canonical-context.json`, `trace-actors.json`, `trace-context-errors.json`, `invalid-contexts.json`.
