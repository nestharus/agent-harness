# WU-0B-02 Proposal: RecordMeta, OpaqueId, and SQLx Serialization Prelude

## Design

Add the shared Phase 0B GraphStore prelude in `src-tauri/src/graphstore/prelude.rs` and expose the contract-facing fixture helpers through `src-tauri/src/contracts/graphstore_prelude.rs`. This WU is type-only: it adds no Tauri commands, no durable domain tables, no repository CRUD, and no value-slice operation.

`RecordMeta` is the canonical metadata block every later Phase 0B row can embed:

```text
RecordMeta {
  created_at: Timestamp,
  updated_at: Timestamp,
  actor: ActorRef,
  policy_version: String
}
```

`Timestamp` is a `String` containing a normalized UTC RFC3339 timestamp ending in `Z`. The validator preserves caller strings and compares them lexically only after checking the fixed UTC timestamp shape, which keeps ordering deterministic without adding a new time dependency. `ActorRef` is a small DTO, not a bare string:

```text
ActorRef { value: String }
```

Using a DTO makes the serialized contract explicit and leaves room for later actor taxonomy work without changing the metadata field from scalar to object.

`validate_record_meta(meta)` returns the supplied metadata unchanged when all invariants hold. It returns `GraphStoreError::InvariantViolation` when `created_at` or `updated_at` is not a normalized UTC RFC3339 timestamp, `updated_at < created_at`, `actor.value` is empty or whitespace-only, or `policy_version` is empty or whitespace-only. The function performs no writes.

## OpaqueId

`OpaqueId<T>` is a phantom-typed ID wrapper:

```text
OpaqueId<T> {
  value: String,
  namespace: String
}
```

The marker type `T` is compile-time only and is not serialized. `OpaqueId<T>::new(value, namespace)` validates both fields and returns `GraphStoreError::InvariantViolation` for any invalid input.

Exact rejection set:

- `namespace` is empty or whitespace-only.
- `value` is empty or whitespace-only.
- `value` or `namespace` contains `/`, `\`, or `:`.
- `value` starts with a known content-hash prefix before separator validation: `sha256:`, `sha512:`, `blake3:`, or `md5:`.
- `value` is `.`, `..`, contains `../` or `..\`, or otherwise encodes a parent-child path through `/` or `\`.

The separator rules intentionally reject mutable parent-path encodings such as `parent/child`; IDs remain stable opaque strings, never paths, path fragments, or content hashes.

## JsonField

`JsonField<T>` is a serde/sqlx codec wrapper for SQLite `TEXT` columns. It serializes the inner value with `serde_json::to_string` and decodes with `serde_json::from_str`, so arrays, maps, nested references, empty arrays, null optional refs, and enum payloads round-trip as JSON data rather than lossy display strings. The wrapper implements SQLite `Type`, `Encode`, and `Decode`.

The implementation accepts any `T: Serialize` for encoding and any `T: DeserializeOwned` for decoding. It uses SQLx's existing `String` text codec under the hood, preserving the repo's current SQLx feature set.

## GraphStoreError

`GraphStoreError` is the shared Phase 0B taxonomy:

- `UnknownRef` with `code() == "unknown_ref"`
- `DuplicateId` with `code() == "duplicate_id"`
- `InvalidEnum` with `code() == "invalid_enum"`
- `InvalidTransition` with `code() == "invalid_transition"`
- `InvariantViolation` with `code() == "invariant_violation"`
- `OptimisticConflict` with `code() == "optimistic_conflict"`
- `SqlxFailure` with `code() == "sqlx_failure"`

Every variant is reachable through a documented fixture under `product-strategy/contracts/fixtures/wu-0b-02/`.

## Contract Module

`src-tauri/src/contracts/graphstore_prelude.rs` re-exports the prelude types and defines fixture DTOs used by contract tests. It does not define a second implementation of validation or SQLx behavior.

## Anti-Scope

- No durable domain tables and no migration file.
- No value-slice service operation.
- No Tauri commands; `phase_0a_scaffold_commands()` remains exactly `["subscribe_workspace_events"]`.
- No provider credentials.
- No `agents` invocation.
- No repository CRUD for later GraphStore schema objects.

## Supported Surface

- Deployment mode: Rust library and contract tests.
- Customer cohort: later Phase 0B schema WUs and internal Rust harness tests.
- Adjacent public paths: GraphStore module exports, contract module declarations, SQLx SQLite usage, WU-0A temp harness, and Phase 0A scaffold command count.
- Blast radius: additive GraphStore prelude module, additive contract module, fixtures, proposal, and tests.
- Migration path: none; this WU exports types and helpers only.
- Rollback path: remove the added prelude module, contract module, fixtures, proposal, and tests.
- Observability: contract tests assert validation behavior, opaque-ID rejection, error codes, JSON SQLx round-trips, timestamp ordering, command-count stability, and absence of durable domain tables.

## Assumptions

- A1: UTC `Z` RFC3339 strings are sufficient for Phase 0B metadata ordering. Evidence: WU-0A-10 already treats timestamp strings as contract text and this ticket asks for an RFC3339 string, not a time object. Invalidated by a revised contract requiring arbitrary RFC3339 offsets or typed chrono values.
- A2: `ActorRef` can be a minimal DTO with a single `value` field. Evidence: the ticket allows a small struct or string and only requires empty-actor rejection. Invalidated by a revised contract requiring actor taxonomy variants.
- A3: Unit-like `GraphStoreError` variants are enough for this prelude. Evidence: acceptance criteria require stable variants and codes, not payloads. Invalidated by a revised contract requiring per-error details.
- A4: The roadmap source file named in the dispatch is absent from this worktree; the ticket includes the WU contract verbatim. Invalidated if the missing roadmap artifact adds stricter requirements not copied into the ticket.

## Test Intent

- RecordMeta validation: verify canonical metadata round-trips through serde, validates unchanged, rejects `updated_at < created_at`, empty actor, and empty policy version. Risk: later rows accept invalid shared metadata. Level: unit/particular-integration. Fixtures: `record-meta-*.json`. Assumptions: A1, A2.
- OpaqueId rejection: verify a valid typed ID preserves namespace/value and invalid path separator, content-hash prefix, empty namespace, and parent-path encoding all return `InvariantViolation`. Risk: stable IDs become paths or hashes. Level: unit. Fixtures: `opaque-id-*.json`.
- Error taxonomy: verify all seven `GraphStoreError` variants deserialize from fixtures, match structurally, and return exact `code()` strings. Risk: caller-visible error drift. Level: unit. Fixtures: `graphstore-errors.json` and `error-*.json`. Assumption: A3.
- JsonField SQLx round-trip: insert and fetch each JSON fixture through a real SQLite `TEXT` column using `Encode`, `Decode`, and `Type` and assert arrays, maps, nested refs, empty arrays, null optionals, and enum payloads are unchanged. Risk: lossy JSON stringification or missing SQLx codec. Level: particular-integration. Fixtures: `jsonfield-round-trips.json`.
- Timestamp ordering: assert `updated_at` before `created_at` is rejected before any insert attempt. Risk: invalid historical rows. Level: unit/particular-integration. Fixture: `record-meta-invalid-updated-before-created.json`. Assumption: A1.
- Domain-table absence and command stability: create an in-memory SQLite database, exercise the prelude codec, inspect `sqlite_master`, and assert no durable domain table appears; assert `phase_0a_scaffold_commands()` is unchanged. Risk: type prelude leaks schema or commands. Level: particular-integration/static. Fixture source: contract plus crate source.
