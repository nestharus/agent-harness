# WU-0B-07 GraphNode Proposal

## Scope

Implement `GraphNode` as the stable logical object visible to agents and UI. This slice is storage and contract only: it does not enable panes, subprocesses, provider probes, optimizer execution, recovery execution, or agent launch behavior.

## Schema

Add one durable table, `graph_nodes`, with:

- `node_id_value`, `node_id_namespace` as the stable unique logical node ID.
- `workspace_id_value`, `workspace_id_namespace` with a foreign key to `graph_workspaces(workspace_id_value, workspace_id_namespace)`.
- `kind`, `title`, `lifecycle_state`, `privilege_origin`, `trust_state`.
- Nullable soft-reference pairs for `current_revision_id` and `canonical_parent_edge_id`.
- Nullable `created_from_ref` JSON.
- Nullable `deleted_at` timestamp; non-null marks soft deletion.
- RecordMeta fields: `created_at`, `updated_at`, `actor`, `record_policy_version`.
- Indexes on node ID, workspace ID, lifecycle state, and kind.

`current_revision_id` targets WU-0B-12 `NodeRevision` and `canonical_parent_edge_id` targets WU-0B-08 `GraphEdge`, whose tables do not exist in this slice. WU-0B-07 stores those as nullable soft-reference columns rather than declaring impossible foreign keys. Until the target tables exist, non-null values are rejected as `UnknownRef`, which preserves explicit transaction rollback and keeps this WU inert.

## Contract Types

`GraphNode` fields:

```text
GraphNode {
  node_id,
  workspace_id,
  kind,
  title,
  lifecycle_state,
  current_revision_id?,
  canonical_parent_edge_id?,
  privilege_origin,
  trust_state,
  created_from_ref?,
  deleted_at?,
  RecordMeta
}
```

Enums use snake_case serde names and SQLx text codecs:

- `GraphNodeKind`: `initiative`, `work_unit`, `summary`, `evidence`, `question`, `decision`, `blocker`, `worker_output`, `recovery`, `policy_note`, `archive`.
- `LifecycleState`: `active`, `packed`, `unpacked`, `blocked`, `stale`, `recovering`, `archived`, `quarantined`, `deleted`.
- `PrivilegeOrigin`: `system`, `user`, `tool`, `model`, `worker`, `optimizer`, `reviewer`.
- `TrustState`: `trusted`, `derived`, `unverified`, `suspect`, `poison_quarantined`.

## Lifecycle Transitions

`transition_lifecycle(node_id, target_state)` validates and updates state in a transaction. Valid transitions:

- `active -> packed`
- `packed -> unpacked`
- `active -> blocked`
- `blocked -> active`
- `active -> stale`
- `stale -> active`
- any non-deleted state -> `archived`
- any non-deleted state -> `quarantined`
- `quarantined -> recovering`

`deleted` is terminal: no transition out is valid. Illegal transitions return `InvalidTransition`. Transitioning to `deleted` is not part of this WU's valid matrix.

## Test Intent

- Schema creation verifies declared columns, JSON checks, FKs, unique constraints, indexes, and RecordMeta.
- Round-trip verifies byte-equivalent serde output for every field.
- Rollback verifies invalid workspace/revision/parent/state paths leave no durable write.
- Enum tests verify every variant through serde, SQLx encode/decode, and repository insert reachability; unknown variants are rejected by serde and SQLx.
- Lifecycle tests cover all valid matrix entries, invalid examples, and deleted terminal behavior.
- Structural tests verify no operator-visible behavior and no additional table beyond `graph_nodes`.
