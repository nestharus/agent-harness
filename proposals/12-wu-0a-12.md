# WU-0A-12 Proposal: ShellRegionState View Model

## Design

Add a TypeScript-only shell-region view-model contract for Phase 0A. The DTO lives in `src/shell/shell-region-state.ts` and contains the exact camelCase fields from the WU contract:

- `workspaceId: string`
- `activePane: PaneId`
- `selectedNodeId?: string`
- `actionNeededCount: number`
- `passiveProgressCount: number`
- `runtimeConnected: boolean`

The parser lives in `src/contracts/shell-region-state.ts` and exposes `parseShellRegionState(input) -> ShellRegionStateParseResult`. It validates only the documented view-model invariants: non-empty workspace ID, documented `PaneId`, non-negative counters, and boolean runtime connection state. It delegates pane validation to the existing `parsePaneId` contract from WU-0A-11.

## Scope

- Define the `ShellRegionState` TypeScript DTO.
- Define the `ShellRegionStateError` union: `EmptyWorkspaceId`, `UnknownPaneId`, `NegativeActionNeededCount`, `NegativePassiveProgressCount`, and `InvalidRuntimeConnected`.
- Add fixtures for canonical states spanning every documented `PaneId` variant.
- Add error fixtures for every documented parser error variant.
- Add Vitest coverage for fixture round-trip, pane coverage, type-level DTO enforcement, and error behavior.

## Anti-Scope

- No Rust contract, Tauri command, or IPC changes.
- No router state, store, workspace state, or IPC subscription wiring.
- No GraphStore, provider, agent, worker, optimizer, evidence, cost, or recovery implementation.
- No pane UI implementation beyond consuming the existing `PaneId` taxonomy.

## Supported Surface

- Deployment mode: local Phase 0A desktop scaffold.
- Customer cohort: developer/test harness consumers only.
- Public paths: TypeScript contract importers and shell view-model consumers.
- Adjacent paths: `PaneId` parsing remains owned by WU-0A-11; router, stores, IPC, and Rust contracts remain unchanged.
- Migration path: additive DTO, parser, fixtures, and unit tests.
- Rollback path: remove the WU-0A-12 contract, DTO, fixtures, and tests.
- Observability: Vitest verifies parser success/error behavior and fixture parity. The parser is a pure function with no imported router, store, or IPC client dependency.

## Assumptions

- A1: The WU contract is complete without Rust parity. Evidence: ticket says this WU is TypeScript-only and explicitly forbids Rust changes. Invalidated by a revised ticket requiring Rust serde fixtures or commands.
- A2: `ShellRegionState` uses camelCase serialization. Evidence: ticket schema field names are camelCase and this is a TypeScript-only DTO. Invalidated by a revised contract requiring snake_case storage or IPC serialization.
- A3: The parser should return a WU-0A-11-style result object rather than throw for documented validation failures. Evidence: WU-0A-11 uses `{ ok, value | error }` for exact-match parser results and this ticket describes `Result<ShellRegionState, ShellRegionStateError>`. Invalidated by a revised local convention requiring exception-based parser errors.
- A4: Parser purity is satisfied by keeping the function dependency-free from router, store, and IPC modules. Evidence: ticket forbids mutation of route state, workspace state, or IPC subscriptions, and the current Phase 0A scaffold has no shell state store or IPC client to mutate. Invalidated by adding a stateful shell registry that the parser imports.

## Test Intent

- DTO fixture parity: verify canonical fixture states parse and round-trip with matching `workspaceId`, `activePane`, optional `selectedNodeId`, counts, and `runtimeConnected`. Risk: TypeScript DTO drifts from the WU contract. Level: unit/typecheck. Fixtures: `canonical-states.json`. Assumptions: A2.
- Pane variant coverage: verify `parseShellRegionState` accepts every documented `PaneId` as `activePane`. Risk: shell state rejects a pane documented by WU-0A-11. Level: unit. Fixtures: `canonical-states.json`, WU-0A-11 `pane-ids.json`. Assumptions: A3.
- Parser error behavior: verify one fixture case per documented `ShellRegionStateError` variant. Risk: invalid shell state silently enters the shell view model. Level: unit. Fixtures: `parse-errors.json`. Assumptions: A3.
- Type-level enforcement: verify `ShellRegionState` rejects unknown panes and wrong runtime connection types at TypeScript compile time. Risk: TS callers can construct values outside the DTO contract. Level: unit/typecheck. Fixture source: DTO type declarations. Assumptions: A2.
- Parser purity assumption: document that no mutation assertion is possible because Phase 0A has no router/store/IPC client dependency in this parser. Risk: parser starts causing hidden side effects. Level: unit/static assumption. Fixture source: import boundary review. Assumptions: A4.
